# Video script — ~60–90 seconds

Plain spoken track for Demo mode. Record the live app: https://harvester-risk-atlas.streamlit.app/

**Setup:** Open demo → sidebar → toggle **Demo mode** → species locks to *Arcangelisia flava* (abutra).

---

## Script

**[Map · ~15s]**  
“This is the Harvester Risk Atlas — EthnoHACK Track 3. Each marker is a medicinal species in the Philippines and Southeast Asia. Color is the Harvest Pressure Index band; size scales with the score. Demo mode picks abutra — moderate pressure, driven more by harvest proxy than by Red List status.”

**[Dossier · ~25–30s]**  
“Continue to the dossier. Four transparent components: rarity, climate stress from WorldClim, harvest proxy from GBIF timing and density, and protected-area gap from WDPCA Philippines. Bars and waterfall show the weights — thirty, twenty-five, twenty-five, twenty. We flag data gaps honestly: IUCN is not linked without an API token, and we never invent a category. You’ll also see a risk archetype chip and a decade histogram from GBIF years.”

**[Field brief · ~15–20s]**  
“Last step — the field brief. Download HTML or PDF for stewardship talking points. Research and education only — not a permit, not medical advice.”

**[Close · ~5–10s]**  
“HPI is relative pressure for monitoring. Weights are open. Red List stays separate. That’s the atlas.”

---

## Timing guide

| Segment | Target | On screen |
|---------|--------|-----------|
| Map | 15s | Demo mode on; map + abutra |
| Dossier | 25–30s | Components, gaps, archetype |
| Brief | 15–20s | Show download buttons |
| Close | 5–10s | Optional Methods glance |

Total ≈ **60–75s** spoken; stretch dossier line if you need ~90s. Cap video ≤10 min on Devpost (pad only with silent UI walk if required — keep spoken core short).

## Do / don’t

- **Do** say “not a permit” and “IUCN never invented.”  
- **Don’t** claim efficacy, DENR authority, or invented Red List categories.  
- **Don’t** open Cursor IDE on camera — use the Streamlit Cloud URL.
